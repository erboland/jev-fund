# Contributor Covenant Code of Conduct

## Our Pledge

We pledge to make participation in this project a harassment-free experience for everyone.

## Our Standards

- Be respectful and precise, especially about P&L and risk.
- No investment advice presented as fact.
- No harassment, trolling, or personal attacks.

## Enforcement

Report unacceptable behavior to the maintainer via GitHub issues (or email listed on the GitHub profile). Maintainers may remove comments, lock threads, or ban contributors.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
