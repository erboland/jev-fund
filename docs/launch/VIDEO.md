# Demo video notes

Record a 30–45s pass:

1. Open the dashboard (full desktop width).
2. Point at NAV / P&L (including a red number if present).
3. Scroll or click **Losses**, then **Buys**, then **Holdings**.
4. Let the opening replay run — “This tick”, NAV, and the tape should change several times in a few seconds. Use `?tape=demo` while recording (fastest), or `?tape=fast` for a slightly slower pass. Run `npm run record:demo` to regenerate `docs/assets/demo.gif` and `demo.mp4`.
5. End on the footer: X @QinvestingAI and qinvesting.ai.

Attach that file to the X post. For HN/Reddit, upload to the repo `docs/launch/` or Streamable/YouTube and paste the link.
